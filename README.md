# volfora-ecommerce
E-commerce store development for tactical gear, optics &; firearms (volfora.eu)
### 🌐 Live Website
[volfora.eu](https://volfora.eu)

### 🛠️ Key Contributions & Features
* **Store Architecture & UX:** Designed an intuitive navigation and categorization system for a large catalog (firearms, optics, tactical gear, footwear).
* **B2B Functionality:** Implemented dedicated B2B structure for European business clients.
* **Custom Integrations:** Set up gift vouchers, consignment listings, and shooting range service sections.
* **Performance:** Optimized for fast loading speeds and responsive viewing across desktop and mobile devices.
